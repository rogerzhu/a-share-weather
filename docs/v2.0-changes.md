# 当前行为

本目录发布的脚本按条目分开打分，没有把美股、日经、韩股合成一行。

## 日期

美股、VIXY、日经、韩股：该市场正在交易就用盘中涨跌幅，已经收盘就用行情上最近一个交易日的收盘。没有涨跌幅才记灰。

- 美股和 VIXY：美东 9:30–16:00。新浪时间是北京时间，21:30 后属于当晚那一盘，凌晨印出的收盘属于前一个美股交易日。
- 日经：东京 9:00–11:30、12:30–15:00。
- 韩股：首尔 9:00–15:30。
- 周末视为已收盘。

## 计分

绿 1、黄 0.5、红 0，灰不进分母。满足率 ≥75% 为晴，≥55% 为多云，≥40% 为阴，其余为雨。

官方制造业 PMI 同时进入「中国数据」和「PMI」。M1 同时进入「中国数据」和「M1 / M2」。同一件事会算多次。

满足率不是上涨概率。
